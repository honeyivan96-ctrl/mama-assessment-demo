# 妈妈测评管理后台使用说明

发布版本：2026-11-03

后台入口：https://honeyivan96-ctrl.github.io/mama-assessment-demo/admin.html

## 日常操作

1. 用原管理密码登录。账户安全页面可修改密码或退出全部设备，改密成功后需重新登录。
2. 密码管理可生成单个或批量测评密码，设置自定义测试编码、批次、渠道、备注和有效期；默认每个密码3次，成功保存测评才计一次。
3. 生成后先复制或导出。新生成密码使用加密存储，再次查看完整密码需验证管理密码。历史密码仅存有摘要，不能恢复原文，仍可继续使用。
4. 发送状态分为未知、未发送、已发送；使用次数另列显示，两者独立。历史密码发送状态保留为未知，避免推测。
5. 补测在现有配额上增加次数，不清空已使用记录。换发可关联旧密码并选择停用旧密码。
6. 测评记录支持按时间、编码、类型等搜索，点击详情查看前置信息、逐题选择及原始分析报告。
7. 原报告保留当时快照。重新计算只供预览，明确发布新版后才替换对外分享版本，旧版仍可在后台查看。
8. 结果分享可关闭或恢复。作废不删除原答卷，返还机会会增加可用配额，同一答卷不能重复返还。
9. CSV导出覆盖当前筛选结果而非仅当前页；普通导出最多10,000条，完整密码最多100条且需再次验证。超出请缩小筛选范围。
10. 操作日志记录生成、改密、发送、补测、导出、作废、报告发布等关键操作，不保存明文密码。

## 技术与维护

前端为GitHub Pages静态站点，服务端为Supabase mama-v2函数，数据库访问限制为服务端角色。
管理员凭据使用PBKDF2-SHA256（600,000次），改密通过凭据版本使旧会话失效。新测评密码为AES-GCM加密，密钥从已有APP_SECRET派生；不要随意更换APP_SECRET，避免影响旧密码验证和新密码恢复。

数据库升级为增量修改，保留已有密码、计数、答题及报告，并创建一次受保护的升级备份。回退前应保留升级后的新增数据，不要直接用旧备份覆盖在线数据库。原函数和旧前端可回退，但旧后台不支持新管理功能；改密后应使用新后台，旧后台凭据逻辑不兼容。

发布前验证：真实Postgres兼容数据库事务集成、权限隔离、加密恢复、改密会话撤销、生成与补测幂等、报告版本与分享开关，以及现有测评与结果保存测试。
