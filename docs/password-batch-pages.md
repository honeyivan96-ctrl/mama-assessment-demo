# 密码批次管理（2026-11-03）

密码管理拆为三个页面：生成密码、密码批次、批次详情。

生成密码默认自动建立一个本次生成批次，也可选择已有批次。批次列表点击“进入批次详情”，查看该批密码的交付与使用状态，支持批量标记、停用、删除及恢复。此前没有指定批次的密码放在“历史未分批密码”。

“导出本批全部密码”导出整批未删除密码；“导出筛选密码”导出当前筛选结果，包含全部分页。CSV只有“测评密码”一列。登录管理员可直接导出，不再要求重复输入管理密码；未登录不能导出，服务端仍记录导出日志。每次最多10,000条，服务端按100条分段读取。

只存摘要的历史密码无法恢复，导出时跳过，整批均无法恢复则提示失败。删除记录仍在回收站，恢复后需单独启用。
