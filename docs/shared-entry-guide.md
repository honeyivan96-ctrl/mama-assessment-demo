# 统一测试码与匿名浏览器编号（2026-11-10）

所有买家可以收到同一网址和测试码。默认统一测试码为 MAMA2026，管理员可在后台“统一测试码”中自定义和更新（4—32位英文字母、数字或下划线，自动转为大写），并复制自动发货文字。保存时校验设置版本，重试不重复更新，变更留操作日志。

每个浏览器第一次验证时生成随机凭证，保存在该浏览器网站存储中。服务端仅保存凭证的加密摘要，建立独立内部ID与3次测评权益；成功保存报告才扣次数。重复验证、刷新、更新统一码不会重置同一浏览器的已用次数，并发提交也不会超出额度。

后台“用户记录”可搜索内部ID、按已用次数筛选、启用或停用该编号，以及查看关联答卷与分析报告。“问卷记录”保留所有答卷，旧独立密码管理作为历史入口保留。

更新统一码仅改变后续验证所需的代码；已发放且未过期的答题会话仍有效。暂停入口表示暂停新的统一码验证，不会自动撤销正在答题的会话。若需限制某个浏览器，使用用户记录中的停用功能。

浏览器编号不是小红书账号，也不验证订单。换设备、换浏览器或清除网站存储可能产生新编号，不能保证“每个自然人仅3次”。不要宣传已识别买家身份。共享码如果被转发，获得者也可能进入测评。

旧密码、历史答卷、报告分享链接与原有统计起点保留。订购量仍是核销代理口径：统一码模式按每个浏览器编号首次成功完成计1次，历史独立码按首次成功完成计1次，不是小红书实际成交订单。

安全：管理接口需有效管理员会话；统一码加密保存，原始浏览器凭证不入库；新增表启用RLS，仅服务端可访问；日志不记录完整统一码、凭证或密钥。管理员密码未改变。
