# 手机HTTPS图片下载

修复内置浏览器忽略data/blob下载：四种妈妈形象提供同源HTTPS PNG，完整报告按页上传私有Storage桶，并签发15分钟有效的HTTPS原图和附件下载链接。每张图提供下载、打开原图、复制图片链接，点击及准备失败都有可见反馈。原始长按预览保留，上传失败可重试。

图片上传只接受现有且分享开启的报告链接凭证，不接受任意路径；仅PNG，5MiB以内，900像素宽且高度不超过7400，最多8页。服务端使用私有桶，匿名无Storage读写策略，密钥不发前端。存储路径为报告ID的HMAC及固定页号，重复准备覆盖同一页，不无限追加文件。关闭分享后不再签发新链接，已签发链接在15分钟后失效。

用户点击保存仍需手机浏览器或系统确认，网页不能直接写相册。内置浏览器若禁止下载，可打开HTTPS原图或复制图片链接到系统浏览器保存。测试覆盖HTTPS地址、PNG校验、大小边界、访问控制、无密钥泄露、前端准备失败及重试、状态反馈、既有问卷与计次回归。
