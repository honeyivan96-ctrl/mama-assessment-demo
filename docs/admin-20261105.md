# 2026-11-05 管理后台更新

数据总览按北京时间展示当日/累计首页浏览量、订购量（核销口径）、有效答卷数，以及当日/累计妈妈类型分布。首页每次实际显示计一次，刷新会再计；同一个请求重试只计一次；后台和预览页不计入。无采集姓名、联系方式、完整页面URL或设备指纹。随机事件标识仅用来去重。

订购量当前按每个密码首次成功完成测评计一次，未接入小红书支付订单，不能作为实际成交量。作废记录不计入有效答卷，但不撤销首次核销的历史事实。

问卷密码管理为两个页签：生成密码、密码清单。默认生成100个，格式为CS_4827（2位英文字母、下划线、4位随机数字）。每个前缀最多10,000种数字组合，已存在密码不重复生成，包括回收站密码。支持旧格式密码继续使用。导出为真正的xlsx工作簿，仅一列密码；登录后导出不重复验证管理密码。

密码清单下拉可筛选未使用、使用1/2/3次，支持批量删除和回收站恢复。

按用户明确确认，历史数据仅统计归零，采用stats_since起算时间，不删除密码、答卷或报告，不使旧链接失效；时间记录于操作日志。后续重新执行结构SQL不会自动改变统计起点。

验证涵盖：100个短密码唯一性及登录，分页导出205个密码的xlsx结构与单列内容，首页重复请求去重，北京日界线，作废答卷排除，统计归零不删除数据，匿名访问权限拒绝，以及原测评和分享保存功能。
