# 图片保存修复

保存按钮同步打开可见窗口，图片按需生成，错误与重试在窗口内显示。图片预览不依赖原生分享接口；手机可长按保存，支持系统面板时另提供保存按钮。生成、插画读取、PNG转换和原生分享均有超时反馈。不会把分享完成误报为已存入相册。

完整报告按内容块分为多张PNG，每张宽900像素、高不超过7400像素；超长文字段落也按行拆分，保留全部内容。每张独立提供下载，系统支持时可把多张图片一同传入系统面板。编码完成后释放画布像素内存，避免同时预生成形象卡和长报告。

回归验证覆盖实际报告绘制、全部四部分与五项维度、分图文字无丢失、图片生成失败/超时/重试、系统面板拒绝/取消/不返回、关闭窗口后异步结果处理、桌面文件下载。浏览器页面可验证PNG生成和下载；实体手机相册写入仍由用户在操作系统中确认。
